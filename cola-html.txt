Estrutura básica de um documento HTML
Todo documento HTML moderno começa com uma estrutura semelhante a esta:

<!DOCTYPE html>
<html lang="pt-BR">
<head>
    <meta charset="UTF-8">
    <meta name="viewport" content="width=device-width, initial-scale=1.0">
    <title>Meu primeiro site</title>
</head>
<body>
    <h1>Olá, mundo!</h1>
    <p>Este é meu primeiro site.</p>
</body>
</html>
O que cada parte faz:

<!DOCTYPE html> — informa que o documento utiliza HTML5.

<html> — elemento principal da página.

<head> — contém configurações e metadados.

<meta charset="UTF-8"> — permite exibir acentos corretamente.

<meta name="viewport"> — ajuda a adaptar o site a celulares.

<title> — define o título da aba do navegador.

<body> — contém o conteúdo da página.

<h1> — cria o título principal.

<p> — cria um parágrafo.

3. Principais tags HTML e como usar
HTML possui muitas tags, e algumas são específicas para determinados tipos de conteúdo. A seguir estão as principais, organizadas por categoria.

3.1 Títulos e textos
<h1> até <h6>

Títulos do maior nível de importância ao menor.

Exemplo: <h1>Título principal</h1>

<p>

Cria um parágrafo.

Exemplo: <p>Meu texto aqui.</p>

<br>

Quebra a linha.

Exemplo: Primeira linha<br>Segunda linha

<hr>

Cria uma divisão temática, normalmente uma linha horizontal.

Exemplo: <hr>

<strong>

Indica importância; normalmente aparece em negrito.

Exemplo: <strong>Atenção!</strong>

<b>

Destaca visualmente em negrito.

Exemplo: <b>Texto em negrito</b>

<em>

Dá ênfase ao texto.

Exemplo: <em>Texto enfatizado</em>

<i>

Representa texto em uma voz ou estilo diferente.

Exemplo: <i>Termo estrangeiro</i>

<u>

Marca um trecho com anotação visual, normalmente sublinhado.

Exemplo: <u>Texto marcado</u>

<s>

Indica conteúdo que deixou de ser válido ou relevante.

Exemplo: <s>R$ 100</s>

<small>

Texto de menor destaque, como observações.

Exemplo: <small>Termos e condições</small>

<mark>

Realça um trecho.

Exemplo: <mark>Importante</mark>

<sub> e <sup>

Texto subscrito e sobrescrito.

Exemplo: H<sub>2</sub>O e x<sup>2</sup>

<pre> e <code>

Exibem texto pré-formatado e trechos de código.

Exemplo: <pre><code>echo 'Olá';</code></pre>

<blockquote>

Citação em bloco.

Exemplo: <blockquote>Uma citação.</blockquote>

<q>

Citação curta dentro do texto.

Exemplo: <q>Olá!</q>

<abbr>

Marca uma abreviação.

Exemplo: <abbr title="HyperText Markup Language">HTML</abbr>

<cite>

Indica o título de uma obra citada.

Exemplo: <cite>Dom Casmurro</cite>

<time>

Representa uma data ou hora.

Exemplo: <time datetime="2026-10-22">22/10/2026</time>

<span>

Agrupa um trecho em linha para aplicar estilos ou manipulações.

Exemplo: <span class="destaque">Olá</span>

Tag

Para que serve

Exemplo

Reproduz vídeo

Adiciona legendas ou faixas de texto

Agrupa uma mídia ou ilustração

<figure>...</figure>

Legenda de uma figura

<figcaption>Minha foto</figcaption>

<iframe>

Incorpora outra página ou conteúdo

<iframe src="pagina.html" title="Conteúdo"></iframe>

<map> e <area>

Criam áreas clicáveis em uma imagem

<map name="mapa">...</map>

Exemplos completos:

<!-- Link -->
<a href="https://www.google.com" target="_blank" rel="noopener">
    Abrir Google
</a>

<!-- Imagem -->
<img src="foto.jpg" alt="Paisagem" width="300">

<!-- Áudio -->
<audio controls>
    <source src="musica.mp3" type="audio/mpeg">
    Seu navegador não suporta áudio.
</audio>

<!-- Vídeo -->
<video controls width="400">
    <source src="video.mp4" type="video/mp4">
    Seu navegador não suporta vídeo.
</video>
O atributo alt descreve a imagem para leitores de tela e também ajuda quando ela não carrega.

3.5 Formulários — muito importantes para PHP
Formulários são usados para enviar informações do navegador para o servidor.

Tag

Função

<form>

Define o formulário

<label>

Identifica um campo

<input>

Campo de entrada

<textarea>

Campo de texto longo

<button>

Botão

<select>

Lista de opções

<option>

Opção da lista

<optgroup>

Agrupa opções

<fieldset>

Agrupa campos relacionados

<legend>

Título do grupo

<datalist>

Sugestões para um campo

<output>

Exibe o resultado de um cálculo

<progress>

Indica progresso

<meter>

Indica um valor dentro de uma faixa

Tipos comuns do <input>:

text — texto.

password — senha.

email — e-mail.

number — número.

date — data.

time — horário.

checkbox — caixa de seleção.

radio — opção exclusiva dentro de um grupo.

file — envio de arquivo.

submit — envio do formulário.

reset — restauração dos campos.

tel — telefone.

url — endereço de site.

search — campo de pesquisa.

hidden — valor não exibido como campo visível.

range — controle deslizante.

color — seletor de cor.

month — mês e ano.

week — semana do ano.

datetime-local — data e hora locais.

Exemplo:

<form action="receber.php" method="POST">
    <label for="nome">Nome:</label>
    <input type="text" id="nome" name="nome" required>

    <label for="email">E-mail:</label>
    <input type="email" id="email" name="email" required>

    <label for="idade">Idade:</label>
    <input type="number" id="idade" name="idade" min="1">

    <label for="mensagem">Mensagem:</label>
    <textarea id="mensagem" name="mensagem"></textarea>

    <button type="submit">Enviar</button>
</form>
Atenção: o atributo name é essencial para que os campos sejam enviados com seus nomes para o PHP. O atributo id ajuda a associar o campo ao seu label.

method="GET": envia dados pela URL, útil para buscas e filtros.

method="POST": envia dados no corpo da requisição, comum em cadastros.

action="receber.php": indica qual arquivo receberá os dados.

3.8 Tags especiais e menos comuns
<ruby>, <rt> e <rp> — anotações de pronúncia, usadas principalmente em idiomas asiáticos.

<bdi> — isola um trecho cuja direção do texto pode ser diferente.

<bdo> — força a direção do texto com dir.

<wbr> — indica um ponto possível de quebra de linha.

<data> — associa um conteúdo legível a um valor de máquina.

<ins> — indica conteúdo inserido.

<del> — indica conteúdo removido.

<menu> — representa uma lista de comandos ou itens.

<slot> — define um espaço de conteúdo em Web Components.

<elemento-personalizado> — elementos com nomes próprios podem ser criados seguindo as regras de Web Components.

Algumas tags antigas, como <font>, <center>, <marquee>, <big>, <strike> e <frameset>, são obsoletas ou não recomendadas. Prefira CSS e os elementos modernos equivalentes.
